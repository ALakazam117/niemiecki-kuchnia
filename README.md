# KüchenKlub — niemiecki od kuchni

Polska strona do powtórki przed kartkówką z tematów „Ich esse nie Fleisch” oraz „Du möchtest doch auch einen, oder?”.

## Co zawiera

- 36 fiszek: 18 przedmiotów kuchennych, 8 określeń częstotliwości i 10 słówek o jedzeniu i posiłkach.
- Fiszki w obie strony, filtrowanie, tasowanie, oznaczanie opanowanych słówek i odsłuch niemieckiej wymowy.
- Słowniczek z wyszukiwarką, rodzajnikami, liczbą mnogą i przykładami.
- Wyjaśnienie mianownika i biernika zaimków einer/einen/eine/eins/welche, przeczeń i form dzierżawczych.
- 16 ćwiczeń gramatycznych z informacją zwrotną.
- Losowa kartkówka: 12 pytań, wynik, wyjaśnienia błędów i powtarzanie samych błędów.

## Uruchomienie

Otwórz `index.html` w przeglądarce lub opublikuj katalog jako statyczną stronę. Nie wymaga instalowania bibliotek ani budowania projektu.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Postęp i ostatni wynik zapisują się wyłącznie w lokalnej pamięci przeglądarki. Strona nie ma kont, analityki ani serwera. Wymowa zależy od obsługi Web Speech API i dostępnego głosu niemieckiego na urządzeniu. Fonty pobierane są z Google Fonts; przy braku połączenia używana jest czcionka systemowa.

Zakres tematyczny sprawdzono w [oficjalnym podglądzie Hueber, lekcja 3, s. 36–37](https://www.hueber.de/shared/elka/Internet_Muster/Red1/9783193610843_Muster_1.pdf). Strona jest niezależną pomocą edukacyjną. Przykłady i quizy opracowano na potrzeby tej strony; nie jest to kopia ćwiczeń z podręcznika.
